# Data Structures in C

This project contains implementations of fundamental data structures in C using dynamic memory allocation.

## Implemented Structures

- Singly Linked List
- Doubly Linked List
- Circular Linked List
- Hash Table (with chaining)

## Operations Implemented

- insertion
- deletion
- traversal
- search by key
- counting elements with specific conditions
- memory deallocation

## Technical Concepts Used

- dynamic memory allocation (malloc / free)
- pointers
- structures
- linked list navigation
- hash functions
- collision resolution using chaining
- file reading (.txt input)

## Example Input File

The project uses `.txt` files for loading structured data into memory.
